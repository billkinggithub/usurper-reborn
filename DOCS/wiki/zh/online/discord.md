Discord 机器人可以在服务器所有者启用的频道中，根据已发布的英文百科回答问题。提及该机器人并问一个具体问题，例如：`@UsurperBot how does Favor work?`

## Ask 会做什么

Ask 会在已发布的百科中搜索与你问题匹配的页面。它如何回答取决于服务器：

- **启用 Claude API 时。** 机器人会把最匹配的百科摘录和你的问题发送给语言模型 Claude，并回复一段约 120 词、通俗简短的答案，随后附上它所用页面的链接。该模型只能使用这些摘录。如果摘录没有覆盖你的问题，答案会说明这一点。
- **未启用时。** 机器人会回复匹配页面中的简短摘录和链接。

当匹配页面有一个标题与你问题相符的剧透折叠块时，回复会提到该折叠块的名称并链接到页面；它不会陈述折叠块里有什么。

如果没有页面匹配，机器人会说明，并且不调用模型。Ask 从不检查玩家存档或私人游戏数据，剧透披露文本也不在它能看到的范围内；它只能看到每个折叠块的标题。回复不显示链接预览。

与《篡位者重生》无关的问题，例如其他游戏、编程或一般闲聊，会被拒绝，且不附来源链接。

## 限制

- 一个问题最多 300 个字符。
- 每位用户每十秒可以问一次，服务器每分钟处理的问题数量有限。
- 启用 Claude API 时，每位用户和整个服务器还有每日限制。超过限制后，你会改为收到摘录回复。
- 如果模型调用失败或其答案过长，你也会收到摘录回复。

问题不会被转发到游戏内的八卦频道。可用性取决于所有者是否启用了允许的频道并部署了构建好的搜索索引。

## 报告缺陷

Ask 和 Suggest 用于百科，而不是游戏缺陷。要报告缺陷，请在游戏中按 `!` 或输入 `/bug`，或打开 GitHub issue；参见[报告缺陷](/wiki/zh/getting-started/reporting-bugs/)。

## 建议改进

拥有所有者所配置的任意一个角色的受信任助手可以使用 `@UsurperBot suggest: ...` 或 `@UsurperBot suggestion: ...`。这两个词都不区分大小写，冒号前可以有也可以没有空格。请描述缺失的说明或不正确的说法，而不是要执行代码的指令。

建议会进入审核队列。它们不会编辑生产站点或发布页面。所有者会根据游戏代码和导出数据审查该说法，然后准备一个只涉及文档的拉取请求。下一次经审核的发布或获批准的部署会将其发布。

如果未启用 Suggest，请让所有者配置受信任角色。两个功能都受速率限制。
