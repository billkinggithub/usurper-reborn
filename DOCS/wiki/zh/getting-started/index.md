先从[连接方式](/wiki/zh/getting-started/connections/)和[账号与角色栏位](/wiki/zh/getting-started/accounts/)开始，然后创建一个角色，并进行一次简短的[首次远征](/wiki/zh/getting-started/first-hour/)。如果出了什么问题，请参阅[报告缺陷](/wiki/zh/getting-started/reporting-bugs/)。

## 创建角色

你的种族和职业会影响创建时的数值以及后续成长。选择之前，请先比较[职业目录](/wiki/zh/characters/classes/)和[种族目录](/wiki/zh/characters/races/)。并非每个种族都能选择每个职业；角色创建画面才是可用组合的最终依据。

职业会改变你在战斗中消耗资源的方式。武技通常消耗耐力，而法术消耗法力。购买或使用之前，请阅读实际的法术或能力描述。

## 掌握操作

这是一款菜单驱动的游戏。请阅读当前地点显示的按键，而不是记住另一个菜单里的按键。主街可以使用分区、经典或屏幕阅读呈现方式，随着角色成长会出现更多操作。

使用 Status 查看你的生命、装备和精神。远征前需要治疗时，先去治疗师那里。拜访等级大师是角色成长的一部分。

## 选择节奏

单人游戏给你一个属于自己的世界和存档。在线游戏与其他玩家共享一个世界，NPC 的生活也会持续。日常系统与社交系统在两种模式下的表现可能不同；[在线指南](/wiki/zh/online/)说明了可以预期的情况。
